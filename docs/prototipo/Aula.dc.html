2. Soma, média e maior valor

Quase todo algoritmo com listas segue o mesmo molde: um acumulador começa vazio, o laço visita cada elemento e o acumulador vai sendo atualizado.

notas = [7.0, 8.5, 6.0, 9.0]
soma = 0
for n in notas:
    soma += n
print(soma / len(notas))

Atenção: se a lista estiver vazia, len(notas) é 0 e a divisão dá erro.
